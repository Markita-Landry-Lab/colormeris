How it works
  1. Open a PDF, PNG or JPG (or drop / paste it). For PDFs pick the page and resolution.
  2. Add one panel per heatmap.
  3. Grid: click the outer top-left and bottom-right corners of the heatmap, then set rows, columns and labels.
  4. Colorbar: click the two ends of the colorbar along its middle, then click at least two tick marks and type their values.
  5. Check the results (toggle Reconstruct to compare colors), then download CSV or export the project zip to reload later.
  1. Open a PDF, PNG or JPG of the IVIS figure (or drop / paste it). For PDFs pick the page and resolution.
  2. Grid (optional): if the animals are arranged in boxes, click the outer top-left and bottom-right corners of the grid, then check rows, columns and box names.
  3. Colorbar: click the two ends of the colorbar, then click at least two ticks and type their values (e.g. 0.4e8 for 0.4 × 10⁸).
  4. Regions: draw ellipses (Shift = circle), rectangles (Shift = square) or polygons. A region drawn in one box is copied into every box; drag a copy to nudge it in that box only.
  5. Grayscale pixels (the photo) count as no signal. Read the results table, download the CSV, or export the project zip.

Switch tools at the top at any time: the file and both tools' work stay, and one project zip holds everything. Scroll to zoom, drag to pan, ← → to flip PDF pages, drag handles to adjust. Esc cancels, Ctrl/⌘+Z undoes; change the hotkeys in Settings. Everything runs in your browser; files are never uploaded, except page images sent to OpenRouter when you run the agent.

          Settings

          Agent

          Used by the Agent card of the heatmap tool. Settings are saved in this browser as you change them.

          Get a key at openrouter.ai/keys. Without Remember, the key is forgotten when you close the page. The base URL is for OpenRouter-compatible proxies (such as npm run proxy at http://localhost:8787/api/v1, which adds the key itself); leave it empty otherwise.

          Matching

          How colors are matched to the colorbar. New panels start with these values; changing one here applies it to every panel of that tool in the open project (Undo reverts it). Panels keep their values in the project zip.

          Heatmap

          Cells whose color is further than the ΔE limit from every colorbar color are outlined in red.

          IVIS

          Pixels whose color is nearly gray (CIELAB chroma at or below the threshold) are background with no signal. Colored pixels that match no colorbar color (ΔE above the limit, e.g. colored text) are counted as signal but reported as flagged.

          Hotkeys

          Click Change, then press the new key or combination. A key used by another action moves to this one. Esc (cancel), Space (pan), Enter and Backspace (polygons) and Delete (regions) are fixed.

          ActionKeys

          Import and export

          Save all settings (agent, matching and hotkeys) to a zip, and load them in another browser or after clearing this one.

          Export

          The key is stored as plain text in the zip. Anyone with the file can spend your OpenRouter credit.

          Import

          Replaces the current settings. If the file has no API key, the current key is kept.

          Reset

          Back to the defaults; the API key is kept.
